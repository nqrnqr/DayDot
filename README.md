# DayDot · 日迹

轻量、无压力、本地优先（Local-First）的 Done List 与生活事件记录应用。

## 核心特性

- **清爽事件卡片主页**：分组筛选、搜索、主题色柔和图标、卡片右上角支持 `+`（带默认值确认抽屉）或 `⚡`（一键速记 + 撤销）。
- **默认值极简录入**：例如「引体向上」默认 `20 个`、「练琴」默认 `30 分钟`，点击记录已自动填好默认值，支持快捷档位与步长微调，1 秒确认保存。
- **自定义字段**：支持数值（带单位、默认值、快捷档位）、单选/多选标签、短文本备注。
- **动态主题色事件详情**：
  - **记录视图**：可折叠月历 + 竖向时间轴，支持补记、编辑与删除。
  - **统计视图**：周 / 月 / 年 / 总切换、柱状图（可切次数或数值总量）、4 宫格核心指标（次数、天数、日均、平均间隔）、年度热力图、自定义字段汇总与标签占比。
- **全局查看与趋势**：跨事件的全局月历、全局时间轴、趋势总览与全局热力图。
- **纯本地离线 + PWA**：基于 IndexedDB（Dexie.js）本地持久化，内置 JSON 导出/导入备份；支持 Android 浏览器添加到主屏幕离线运行。

## 本地运行

```bash
npm install
npm run dev
```

手机与电脑在同一局域网时，可在手机浏览器访问终端输出的 `Network: http://<电脑局域网IP>:5173` 直接真机体验。

## 打包构建

```bash
npm run build
```
