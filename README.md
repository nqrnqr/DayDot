# DayDot · 日迹

轻量、无压力、本地优先（Local-First）的 Done List 与生活事件记录应用。

- **在线体验（GitHub Pages）**：https://nqrnqr.github.io/DayDot/
- **仓库地址**：https://github.com/nqrnqr/DayDot

## 核心特性

- **清爽事件卡片主页**：分组筛选、搜索、卡片置顶与直接拖拽排序（支持 Android 触屏与鼠标），右上角支持 `+`（带默认值确认抽屉）或 `⚡`（一键速记 + 撤销）。
- **默认值极简录入**：例如「引体向上」默认 `20 个`、「练琴」默认 `30 分钟`，打开录入抽屉自动预填，点击输入框自动全选便于直输，支持快捷档位与必填校验（`*`）。
- **自定义字段 & 分组管理**：支持数值（单位 + 默认值 + 快捷档位）、单选/多选标签、短文本备注；内置独立分组管理抽屉（拖拽排序、重命名、事件计数、安全删除）。
- **全主题色联动事件详情**：
  - **记录**：可折叠月历（支持左右滑切月、一键回到本月）+ 竖向时间轴，支持补记、编辑与删除。
  - **统计**：周 / 月 / 年 / 总切换、柱状图（支持切换次数或数值总量）、4 宫格指标（记录次数、记录天数、每日平均、平均间隔）、数值汇总、年度热力图及标签占比。
- **多维度趋势视图**：顶部 4 宫格总览（事件总数、记录次数、使用天数、记录天数）+ **周矩阵圆点** / **月双列迷你日历** / **年独立热力图卡片**，支持分组筛选与排序切换。
- **全局查看 & 暗黑模式**：全局月历与时间轴视图；支持「跟随系统 / 浅色 / 深色」三态主题切换。
- **纯本地离线 + PWA**：基于 IndexedDB（Dexie.js）本地存储，内置 JSON 一键导出 / 导入备份。

## 部署与更新说明

本项目通过 GitHub Actions 自动部署到 GitHub Pages（配置文件见 [.github/workflows/deploy.yml](.github/workflows/deploy.yml)）：

1. 每次向 `main` 分支推送代码后，工作流会自动安装依赖、以 `BASE_PATH=/DayDot/` 打包并发布到 `https://nqrnqr.github.io/DayDot/`。
2. 如需修改仓库名，工作流会自动读取新仓库名作为子路径，无需手动改配置。

## Android 手机安装（离线 PWA）

1. 在 Android 手机的 Chrome / Edge 浏览器中打开 https://nqrnqr.github.io/DayDot/ 。
2. 点击浏览器右上角菜单 `⋮` → 选择 **「安装应用」** 或 **「添加到主屏幕」**（已内置 `192×192` / `512×512` 桌面图标）。
3. 首次加载完成后，Service Worker 会缓存应用资源，**日常使用可完全离线、无需代理秒开**；仅在拉取新版本时需要联网。

## 数据隐私与备份

- 公开仓库仅包含前端程序代码与内置演示示例，**你的所有个人记录仅保存在当前设备的浏览器本地数据库（IndexedDB）中**，不会上传到 GitHub 或任何服务器。
- 换设备或清理浏览器数据前，请在 **设置 → 导出 JSON 备份** 手动保存备份文件（请妥善存放在个人目录/网盘，**不要提交到公开仓库**）。

```bash
# 本地构建验证
npm run build
```
